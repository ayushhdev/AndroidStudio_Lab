# LoginPage

A simple Android application built with Kotlin and Jetpack Compose demonstrating a login flow with Home and Profile screens.

## Features

- Login screen
- Home screen
- Profile screen

## Tech Stack

- Kotlin
- Jetpack Compose
- Android Studio / Gradle (Kotlin DSL)

## Getting Started

1. Clone the repository.
2. Open the project in Android Studio.
3. Sync Gradle and run the app on an emulator or device.
